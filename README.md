# China trip 2026

This is a mobile-first shared itinerary generated directly from `travel-plan.md`.

## Update the itinerary

1. Edit `travel-plan.md`. Keep each day's four-column Markdown table in the same shape: Time, Plan, Details, Status.
2. Use one of these status labels: `Booked`, `Planned`, `Flexible`, `Confirm`, `Decide`, or `Idea`.
3. Run `npm run check` and `npm run build` before sharing an update.

## Preview locally

```sh
npm install
npm run dev
```

Open `http://localhost:3000`.

## Share without maintaining a permanent website

ChatGPT Sites is the intended sharing path. Publish when the itinerary is ready, share the resulting URL with the narrowest useful audience, and publish later versions to update the same Site. After the trip, restrict access to yourself or delete the Site.

Every Sites deployment URL is a production deployment. Do not publish passport numbers, booking codes, home addresses, or anything else that should not be visible to the selected audience.
